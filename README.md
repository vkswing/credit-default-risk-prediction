# Credit Default Risk Prediction using Machine Learning

## Overview

This project uses machine learning to predict whether a customer is likely to default on their next credit card payment. The model was built in Python using the Credit Default dataset and compares multiple Random Forest classifiers to identify the best-performing model.

This project demonstrates data preprocessing, supervised machine learning, model evaluation, and performance comparison using Python and scikit-learn.

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- Random Forest Classifier

---

## Dataset

The dataset contains customer financial information including:

- Credit Limit
- Age
- Education
- Marital Status
- Payment History
- Bill Amounts
- Previous Payment Amounts

Target Variable:

- **DEFAULT_NEXT_MONTH**
  - 1 = Customer defaults
  - 0 = Customer does not default

---

## Machine Learning Process

1. Load and explore the dataset
2. Split the data into training and testing sets
3. Train multiple Random Forest models
4. Compare model performance
5. Evaluate using:
   - Accuracy
   - Precision
   - Recall
   - F1 Score
